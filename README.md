# 📐 Geometry Lab

A sleek, cyberpunk-inspired dark-mode geometry calculator built with vanilla HTML, CSS, and JavaScript. Perform fast, accurate area and perimeter calculations inside a responsive, glassmorphic interface.

---

## ✨ Features

- **Futuristic UI/UX**: Dark-mode glassmorphism with ambient neon gradients and micro-animations.
- **Dynamic Dimension Fields**: Input fields adapt automatically depending on whether you are calculating Area or Perimeter.
- **Comprehensive Shape Support**:
  - **Square**: Area & Perimeter
  - **Circle**: Area & Circumference
  - **Rectangle**: Area & Perimeter
  - **Triangle**: Area & Perimeter (complete with triangle inequality validation)
- **Robust Error Handling**: Checks for non-positive dimensions, missing parameters, and invalid geometric properties.
- **Zero Dependencies**: Lightweight, vanilla web stack with no build steps required.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure
- **CSS3**: Custom properties (CSS variables), CSS Grid, Flexbox, glassmorphism, and keyframe animations
- **JavaScript (ES6+)**: Dynamic DOM manipulation and geometric calculation logic
- **Fonts**: Space Grotesk & DM Sans via Google Fonts
